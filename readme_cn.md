# OSM切割工具 v0.1 (OSM PBF Cropping Tool)

这是一个基于 PySide6 开发的图形化界面工具，旨在通过地图交互帮助开发者快速裁剪 OpenStreetMap 的 `.pbf` 数据文件 。此工具内置了坐标系自动纠偏机制，特别适合用于为 OSRM (Open Source Routing Machine) 引擎提取准确的特定区域路网数据 。

## 声明
本工具仅供学习与技术研究使用。在处理、切割或转换测绘数据时，请务必遵守所在国家和地区的相关测绘法律法规!

## 主要功能

* **交互式地图选区**：内嵌 Leaflet 网页地图，支持通过右键菜单快速选取裁剪矩形的起点（左下角）和终点（右上角） 。
* **多地图源切换**：内置三种底图源，包括 OpenStreetMap (WGS84)、高德地图 (GCJ02) 和 Esri 卫星图 (WGS84) 。
* **自动纠偏机制**：当使用 GCJ02 底图（如高德地图）进行选点时，系统会自动将火星坐标系转换为 OSRM 标准支持的 WGS84 坐标系 。
* **防呆坐标处理**：自动比对起点与终点的经纬度大小，无论用户点选顺序如何，都能自动重排为正确的左下/右上对角线坐标 。
* **快捷导入**：支持将 `.osm.pbf` 格式的数据文件直接拖拽至主窗口完成路径录入 。
* **内置坐标转换工具**：提供独立的 WGS84、GCJ02 和 BD09 互相转换对话框工具 。
* **异步后台处理**：切割任务通过 `QThread` 在后台独立线程运行，调用外部命令行执行并实时打印日志，防止主界面卡顿 。

## 环境依赖

* Python 3.x
* 核心依赖库：`PySide6` 
* 外部命令行工具：`osmconvert.exe` (必须已添加至系统的环境变量中，或存放于程序同级目录) 

## 配置文件 `setting.json`

程序启动时会自动读取当前目录下的 `setting.json` 文件 。支持的示例 JSON 配置项如下：
* `map_source`: 启动时默认加载的地图源名称 。
* `output_dir`: 切割完成后文件的默认输出目录 。
* `enable_gpu`: 是否启用 GPU 硬件加速功能 。
* `enable_sandbox`: 是否启用沙盒安全模式 。

## 使用指南

1. **导入文件**：点击“浏览”按钮或直接将 `.pbf` 文件拖入“源文件”输入框中 。
2. **选择范围**：在右侧地图区域找到目标位置，右键点击并选择“切割起点”和“切割终点” 。
3. **执行切割**：确认左侧坐标参数无误后，点击“切割并导出”按钮 。
4. **查看结果**：切割日志将在左下方文本框实时输出，完成后文件将保存至您配置的输出目录中 。
